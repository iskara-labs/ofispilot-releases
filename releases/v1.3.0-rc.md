## Known limitations

- **Unsigned installer** — SmartScreen warning expected
- **Messaging runs in TEST_MODE** — email/SMS are dry-run/simulated, WhatsApp is
  a stub. No message is ever actually sent and no provider credential is stored.
- **No auto-update** — re-run the installer to upgrade; settings and data are preserved
- **Licence validation is local** in this build; remote authority is in progress
- Document Intelligence reads metadata only, never file contents

Full list: `KNOWN_LIMITATIONS.md` and `COMMERCIAL_LIMITATIONS.md`.

## System requirements

Windows 10 64-bit (1809+) or Windows 11 · ~1 GB disk · no additional installs.
